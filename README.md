
# CodeAlpha Task 1: Hangman Game

## Project Description
A simple text-based Hangman game developed using Python.
The player guesses a randomly selected word one letter at a time.

## Features
- Five predefined words
- Maximum of six incorrect guesses
- Random word selection
- Input validation
- Duplicate guess detection
- Win and lose conditions

## Technologies Used
- Python
- random module
- Lists, strings, loops, and conditional statements

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python hangman.py

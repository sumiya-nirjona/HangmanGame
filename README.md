# 🎮 Hangman Game Using Python

## 📌 Project Description

A simple, interactive, text-based Hangman game developed using Python. The player attempts to guess a randomly selected word one letter at a time, with a maximum of six incorrect guesses allowed.

This project demonstrates fundamental Python programming concepts through a fun, console-based game.

## ✨ Features

- **Random Word Selection:** Selects a word randomly from five predefined words.
- **Limited Attempts:** Allows a maximum of six incorrect guesses.
- **Letter-by-Letter Guessing:** Reveals correctly guessed letters in their positions.
- **Input Validation:** Checks user input to ensure valid guesses.
- **Duplicate Guess Detection:** Prevents the same letter from being guessed repeatedly.
- **Win Condition:** Congratulates the player when the word is guessed correctly.
- **Lose Condition:** Reveals the correct word when the player runs out of attempts.
- **Console Interface:** Provides a simple, easy-to-use text-based gaming experience.

## 🛠️ Technologies Used

- Python 3
- `random` module
- Lists and strings
- Loops
- Conditional statements
- Input validation

## 🚀 How to Run

### Prerequisites

- Python 3 installed on your computer.
- A code editor such as Visual Studio Code.

### Steps

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the integrated terminal.
4. Run the following command:

```bash
python hangman.py
```

## 🎯 How to Play

1. Run the program.
2. The game randomly selects a word.
3. Enter one letter at a time to guess the hidden word.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses reduce the remaining attempts.
6. Guess the complete word before making six incorrect guesses to win.
